3.1 引言
近年来，基于模仿学习的视觉运动控制方法能够从专家示范中学习观测到动作的映射，已成为机器人抓取、搬运、装配及双臂协同操作的重要研究方向。Diffusion Policy（DP）以条件扩散模型表示动作序列分布，将机器人当前观测作为条件，通过多步迭代去噪生成连续动作块，并以滚动时域方式闭环执行[1]。其中，CNN-based Diffusion Policy 利用视觉编码器提取图像表征，并以特征调制方式将观测信息传递给一维条件 U-Net。该架构在处理多模态动作分布方面具有优势，也为视觉特征编码环节的改进提供了清晰接口。
然而，采用 RGB 图像的视觉编码方式主要依赖颜色、纹理、物体轮廓以及在数据中学习到的透视线索来推断空间状态。在光照变化、颜色相近、遮挡以及物体高度或相机距离变化等场景下，仅由 RGB 图像推断几何关系可能更为困难。对于抓取、对准、堆叠及插入等机器人操作任务，物体表面距离、操作对象与周围结构之间的相对几何关系都是影响动作生成的重要观测信息。RGB-D 相机中的深度图能够提供从相机到可见表面的距离测量，但直接增加独立深度编码分支可能引入额外参数和推理开销；简单拼接 RGB 与 Depth 也不一定充分利用深度图中明确的几何意义。
DFormerv2 在 RGB-D 语义分割任务中提出几何自注意力（Geometry Self-Attention，GSA）[2]，根据深度差异与空间距离构建几何先验，利用该先验调节 RGB 特征间的信息交互，而不是依赖独立的深度主干提取深度语义特征。原论文在语义分割数据集上的消融实验表明该几何先验具有视觉表示价值，但尚不能据此推断其对机器人动作生成成功率的影响。另一方面，TokenLearner 利用输入特征自适应生成少量空间权重图，从密集空间特征中聚合紧凑的视觉 Token[3]。该机制能够提取任务损失引导下的视觉表征，但原始形式并不显式保留每个 Token 对应区域的深度测量值。
针对上述问题，本章以 CNN-based Diffusion Policy 为基线，研究深度几何信息的轻量化注入与动作条件构造，提出一种基于深度几何注意力与自适应空间特征融合的扩散策略（Geometry-aware Spatial Conditioning Diffusion Policy，GSC-DP）。首先，将 DFormerv2 的 GSA 以低分辨率、单层、残差式结构接入 ResNet18 中间阶段，使 RGB 特征在生成过程中受到深度几何先验的调节；随后，基于 TokenLearner 构建自适应空间特征聚合分支，复用其空间权重提取被关注区域的图像位置、深度和测量有效性，形成视觉—几何联合 Token；最后，通过轻量条件映射与原始视觉条件进行残差融合，保留 CNN-DP 的条件一维 U-Net 和动作扩散目标。
本章的具体工作包括：（1）设计适配 CNN-DP 的轻量化 GSA 视觉编码结构，在保留 ResNet18 主干与动作扩散网络的前提下引入深度几何关系；（2）设计深度关联的自适应空间 Token 表示，将局部视觉表征与二维图像位置、深度测量及有效性信息建立对应关系；（3）构建兼容原始扩散策略的视觉条件接口，并制定独立消融、深度退化、任务成功率及端到端延迟评测方案。上述内容均为方法设计与待验证假设，实验结果将在后续训练与评测完成后填写。

3.3.4 深度预处理和计算开销约束
几何先验计算依赖深度数值的尺度。在工程实现中，深度图需首先统一到米或其他明确的物理单位，再采用整个数据集共享的固定缩放常数，使训练集与测试集具有一致数值意义。不能对每帧深度分别做最小—最大归一化后继续将其解释为真实绝对深度。若仿真深度以毫米保存，需统一换算；无效像素、异常值及传感器饱和区应产生独立有效掩码。
RGB 与 Depth 的裁剪、缩放、翻转等空间增强必须使用一致的几何变换；对于深度值插值方式，需避免在明显深度不连续的区域产生不真实的混合距离。为减少伪几何先验干扰，建议记录有效深度比例并设置固定无效值处理策略。上述措施均是保证方法正确性的必要工程条件，不等同于新的学习模块。

3.4 深度关联的自适应空间特征融合
3.4.1 为什么仅有 GSA 还不够
GSA 的输出仍然是多通道空间特征图。它利用几何差异改变特征交互，但未直接给下游 CNN-DP 提供“某个被关注区域距离相机多远”的紧凑数值描述。若将整个特征图直接全局平均池化，虽然能产生固定维特征，但局部空间位置的直接表征可能被削弱。原始 Diffusion Policy 常通过视觉编码与空间特征聚合向动作网络提供观测条件，因此本章需要研究在保持条件维度固定的情况下，如何组织几何增强特征中潜在的重要区域信息。
TokenLearner 通过可学习空间权重，将密集特征图映射为少量视觉 Token[3]。本章选择该方法不是因为它必然为当前 CNN-DP 加速——它放在 GSA 后面，并不能减少 GSA 已执行的计算——而是因为其显式的空间权重能够为“局部特征—深度测量”对应关系提供现成桥梁。

3.4.4 设计动机：相对几何关系与局部绝对深度的区分
GSA 中依赖  的深度差先验有利于调节像素间几何关系，而式（3-17）的  进一步给出了被 Token 权重关注区域的测量深度。两类信息不同：前者与位置之间的相对距离变化有关，后者保留局部深度尺度。对于深度整体偏移 ，理想有效掩码不变时，深度差项保持不变，而式（3-17）的加权深度会相应变化约 。因此，在 GSA 后端显式加入加权深度，能够向扩散条件提供几何先验中未直接编码的测量数值。
需要避免过度解释：局部加权深度并不等价于夹爪到目标的欧氏距离，亦不是经检测器估计的物体三维位姿。该数值是否真的能够改善控制，需通过“GSA+普通 TokenLearner”和“GSA+深度关联 TokenLearner”的严格对照验证。原始 CNN-DP 中可能已经通过 SpatialSoftmax 聚合二维位置信息，故本章应把“深度关联及与 Token 权重统一”作为改动重点，而非宣称首次引入空间坐标。

3.5.4 闭环推理流程与复杂度
推理时，首先获得长度为  的最新 RGB-D 与机器人状态序列；视觉编码器一次性计算每帧几何增强特征与联合 Token，得到固定条件 ；随后从高斯噪声动作块出发，按照原始 DDPM 或 DDIM 采样器所设定的步数迭代去噪，输出动作预测；最后只执行配置中对应的前  个动作，再次获取观测并重复上述流程。GSA 与 TokenLearner 不在每个去噪时间步重新计算。

3.6 实验设计与结果分析（实测数据待填）
本节实验不采用“同一训练 epoch 强制适配所有基准”的做法，而是在 MimicGen 与 ManiSkill 3 内各自采用具有公开依据的训练与闭环评测设置；所有算法在同一任务内使用相同的专家示范子集、评测初始状态、最大执行步数、评价指标与报告方式。为保持模块效果可归因，本文 CNN-DP 家族（E0–E7）固定原始条件一维 U-Net 与训练配置，仅改变视觉输入和编码结构。对 ACT、BC-RNN、DP3 等不同范式保留其公开合理的结构与动作预测方式，完整披露实现差异。
3.6.1 两类 Benchmark 的任务选择
（1）MimicGen Core。 MimicGen 从少量人类示范生成不同初始状态分布下的大量机器人操作轨迹，提供与 robosuite/robomimic 兼容的仿真环境和任务成功判断[5]。本章选择 stack_three_d1、threading_d2、coffee_d2，分别覆盖连续堆叠、对准穿入和多阶段操作。官方注册的上述三个任务 evaluation horizon 均为 400 步。本章采用每任务 200 条专家示范作为主要训练规模，保留 100 和 1000 条用于数据效率分析。与成功率已接近满分的 Can PH 等经典 RoboMimic 设置相比，这些任务保留了更大的性能分析空间，但模型收益必须由当前复现实验确定，不直接搬用其他论文的成功率当作本实验成绩。
（2）ManiSkill 3。 ManiSkill 3 提供多种机器人操作环境和 RGB-D 视觉观测模式，允许从官方轨迹重放并保存观测，也提供用于评价的任务成功状态[6]。选择 StackCube-v1 和 PegInsertionSide-v1：前者对应物体间的空间位置关系，后者对应精细插入。在本章中分别取官方 100 条示范；执行上限按照官方参考配置取 200 与 300 步。StackCube 的视觉 DP 官方示例明确使用 100,000 optimizer updates；PegInsertionSide 的 100,000 updates 来自官方状态 DP 和视觉 ACT 的同任务设置，本文将其指定为视觉 CNN-DP 的固定研究预算，而不宣称为官方已调优的视觉 DP 标准。

3.6.10 深度关联 TokenLearner 的表征分析
对 E4、E5、E6 在相同观测下离线导出  个空间权重图、加权中心 、有效加权深度  及有效比例 。在有实例 GT 时，设置预先固定的 Token—物体关联规则，例如按某 Token 权重与目标分割掩码的加权重叠比例选出目标相关 Token，并记录“没有合格目标 Token”的失败例子。对于关联成立的 Token，分别计算其重心与物体掩码投影中心的距离、加权深度与目标区域可见表面深度之间的差异。
一个简化的示意计算是：某目标表面深度约为 0.40 m、背景约为 0.85 m；若 Token 权重的 55% 落在目标、45% 落在背景，则加权深度约 0.6025 m；若 90% 落在目标、10% 落在背景，则约 0.445 m。这只是验证为什么空间权重准确性影响深度聚合的算术例子，不是训练模型必然产生的权重或实测结果。 本研究必须直接从真实 E4/E6 checkpoint 导出权重并统计，才能检验 GSA 是否间接帮助几何 Token 对准目标。

3.6.12 深度干预、推理时延与结果边界
在训练参数不变、相同初始状态下对完整 GSC-DP 追加 Depth 干预：局部无效深度、深度噪声、块级打乱、关闭 GSA depth prior、关闭 Token 深度字段等，比较成功率和空间误差变化。此类干预属于本文额外的 robustness study，与 Benchmark 原始标准分数分开报告。Depth 异常导致性能下降只能表明策略依赖深度输入，不能独立证明 GSA 对物体边界的具体机制。
推理开销采用 batch=1、固定相机输入、GPU 同步计时；分别记录视觉编码 、扩散去噪 、完整规划 、CPU 数据处理、峰值显存和参数量。H200 上的训练/rollout 可以并行提高吞吐，但公平时延测量要在独占 GPU 的隔离窗口重做，不能把并发负载下的延迟当成不同方法的计算代价。若 GSA/Token 的时间开销抵消了成功率增益，需要在正文中写明实际权衡。

3.7 本章小结（实测后完善）
本章面向以 CNN Diffusion Policy 为基础的 RGB-D 机器人操作学习问题，提出了 GSC-DP 的完整研究方案。第一个工作点借鉴 DFormerv2 的几何自注意力机制，将当前相机测量的深度差与空间关系用于 ResNet18 中间特征之间的交互，并通过单层残差接入保持原始动作扩散网络不变；第二个工作点借鉴 TokenLearner 的自适应空间特征选择，复用同一组空间权重对视觉表示、图像位置、测量深度及深度有效性进行聚合，构造局部视觉—几何联合条件。
这两个工作点以连续信息流组织：GSA 影响 TokenLearner 的输入特征，TokenLearner 输出携带局部位置和距离信息的条件向量，后者经 FiLM 参与扩散动作的多步去噪。该机制为改善物体结构辨识、局部空间定位和后续动作生成提供了可检验的假设，但模型成功率提升不是由结构设计自动保证的。
实验将使用 MimicGen 的 Stack Three D1、Threading D2、Coffee D2，以及 ManiSkill 3 的 StackCube 和 PegInsertionSide，采用各自有公开依据的训练/评测预算；所有方法在同任务内共享专家示范、官方成功标准和环境初始状态。除直接 CNN-DP 对照外，将比较 RGB-D CNN-DP、Transformer-DP、ACT、BC-RNN 和 DP3，并通过 E0–E7、编码器对照、示范规模变化、深度干预、GSA 特征与注意力统计、Token 深度误差、机器人空间误差和 H200 上的独占时延测量构建综合证据链。
当前文档属于待实验验证的论文初稿。所有成功率、误差、显著性和训练耗时均应由真实 H200 实验记录补入。 待实测完成后，本节须加入本章主表中最关键的量化结论及失败适用边界，避免把预期结果写成既成事实。
